# DOKPLOY-LOG-G07 — Monitoring and prevention

Definir métricas parametrizáveis para root/inodes, Docker storage e maiores
logs: `WARNING`, `CRITICAL`, `EMERGENCY`, com justificativa baseada em
capacidade, taxa observada, retenção e RTO. Detectar log grande/crescimento
rápido/rotação ausente antes de 100%; validar entrega de alerta sem gerar logs
excessivos.
